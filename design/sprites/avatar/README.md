# Дүрийн давхаргууд (character creator)

Дүр нь хэд хэдэн давхаргаас бүрдэнэ. Давхарга бүр нь **52 багана × 100 мөр** текст файл, `.` = тунгалаг.
Бүх давхарга нэг канвас дээр давхцаж зурагдана (`hero-starter.txt`-ийн зураг 8 мөр доош шилжсэн —
дээд 8 мөр малгайд зориулсан зай).

| Хавтас | Юу | Дараалал (доороос дээш) |
|---|---|---|
| `body/base.txt` | толгой, нүүр, хүзүү (үсгүй, нүдгүй) | 0 |
| `eyes/` | нүд | 10 |
| `outfit/` | хувцас + гар + гутал | 20 |
| `extra/` | ороолт гэх мэт | 25 (чихэвч 45) |
| `hair/` | үс | 30 |
| `glasses/` | шил | 40 |
| `hat/` | малгай | 50 |

## Үсгүүд (өнгө)

Хуваалцсан: `O` хүрээ · `S/s` арьс + сүүдэр · `H/J` үс + гэрэлтэлт · `P` нүдний өнгө · `W` цагаан ·
`R` хацар · `M` ам · `F/f` гутал.

Хувцас: `U` үндсэн · `u` цайвар · `g` бараан · `q` зах · `L` товч/хээ · `K` бүс.
Малгай, шил, дагалдах: `a` үндсэн · `b` цайвар · `c` бараан · `d` нарийн хээ (өнгийг `src/lib/avatar.ts`-д тохируулна).

`S`, `H`, `P`, `U`-г ашиглавал хэрэглэгчийн сонгосон арьс/үс/нүд/хувцасны өнгөөр автоматаар будагдана.

## Шинэ зүйл нэмэх (3 алхам)

1. Ойролцоо файлыг хуулаад засна. Жишээ: `hair/messy.txt` → `hair/bun.txt`.
   Мөр бүр яг 52 тэмдэгт, нийт 100 мөр байх ёстой (build алдаа заана).
2. `python -P design/build-app-assets.py` — `src/lib/sprites.ts`-г дахин үүсгэнэ.
3. `src/lib/avatar.ts` → `ITEMS`-д мөр нэмнэ:
   ```ts
   { category: "hair", key: "bun", name: "Боодол үс", price: 350 },
   ```
   `price: 0` = үнэгүй. Хувцас/малгайд `colors: [...]` нэмбэл хэрэглэгч өнгө сонгоно.

`npm run dev` ажиллаж байвал `/character` хуудсанд шууд харагдана.
